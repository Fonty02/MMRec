\section{Experiments}
\subsection{MovieLens\_1M}
This section reports test-set results for several models and multimodal configurations. Tables are grouped by cutoff $k$: one table for @5, @10, @20 and @50. For each row we report Recall, Precision, NDCG and MAP at the corresponding cutoff.

% NOTE: default extractors
\paragraph{Feature extractors used}
Unless explicitly specified in a table row as \emph{CLIP} or \emph{AudioCLIP}, the reported VBPR variants use the following default feature extractors:
\begin{itemize}
    \item Text: MiniLM (sentence-transformer)
    \item Image: ViT (Vision Transformer)
    \item Audio: VGGish-based features
\end{itemize}

\subsection{Conclusions}
The per-cutoff tables above show that multimodal VBPR variants improve over the BPR baseline on several metrics, but the relative gains depend on $k$ and on the exact modality combination. The newly added "CLIP+audio (disaligned)" experiment attains very high recall/ndcg values at some cutoffs (notably rec@20 and ndcg@20/@10), indicating that pairing CLIP-based visual/text embeddings with VGGish audio (disaligned) can boost retrieval-style metrics, while MAP/precision improvements are smaller and more nuanced. 

Recommendations: perform modality ablations, statistical tests, and further checks on alignment and audio feature quality to better understand these mixed results.
